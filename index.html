🔹 🐛 Bug Fixes

XLSX Multiline Content Truncation
  • Issue: Excel cells with multiple lines were imported as only the first line
    • Impact: Data loss when uploading files with multiline cell content
      • Fix: Custom XLSX parser now captures all text runs within inline-string cells
        • Files: `popup.js` (lines 194–202)
          • CSV Multiline Row Inflation
          • Issue: CSV files with multiline quoted cells were parsed as multiple rows
            • Example: `Trylmm.csv` with 31 actual data rows showed as 48 rows
              • Root Cause: PapaParse splitting multiline cells into separate records
                • Fix: Hybrid parser with auto-detection:
                  • Fast path: PapaParse (for well-formed CSVs)
                    • Fallback: Strict RFC4180 parser (for problematic CSVs)
                      • Auto-detection: Triggers on suspicious row counts
                        • Files: `popup.js` (lines 88–210)
                          • Logging: Console and UI logs show which parser was used
                            • Prompt Template Not Auto-Saving
                            • Issue: Prompt template text sometimes not persisting across popup reopens
                              • Cause: Used `change` event which requires blur (focus loss)
                                • Problem Case: User types prompt → closes popup without clicking away → text lost
                                  • Fix: Switched to debounced `input` event + immediate `blur` save
                                    • `input`: Fires on every keystroke, debounced 300ms
                                      • `blur`: Immediate fallback save when element loses focus
                                        • Files: `popup.js` (lines 427–446, removed line 784)
                                          • Prompt Not Saving When Using Column Placeholders
                                          • Issue: Clicking column pills to insert placeholders didn't save the new text
                                            • Example: "Find {{Name}}" → click `+ {{Company}}` → result: "Find {{Name}}" (Company not added)
                                              • Cause: Event timing race — blur saved old content before placeholder inserted
                                                • Fix: Manual `input` event dispatch after `setRangeText()` to ensure save
                                                  • Files: `popup.js` (lines 422–424)
